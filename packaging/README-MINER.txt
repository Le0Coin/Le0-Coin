Le0 Miner
=========
Mines LE0 on your PC. Needs a Le0 wallet account / address.

1. Unzip.
2. Run Start-Le0-Miner.bat (or Start-Le0.bat — same thing).
3. Create / sign in to your wallet account. Save your 12-word seed.
4. Leave the Le0 Miner window open. Closing it stops mining.

Mining only starts when:
- you have a wallet address from your account, and
- you are connected to the live Le0 network (peers >= 1).

No wallet address = no mining.
If peers drop, mining pauses on purpose.

The laptop network host must be online.
If a new Discord download is posted, switch to it.

Wallet files stay in %LOCALAPPDATA%\Le0-wallets
Only download from the official Le0 site or Discord.
